# gs_kadai_03
じゃんけんアプリリッチ版

（1）制作サイトのタイトル
甲虫王者！熱血じゃんけんバトル（昔あそんだムシキング風アーケードゲーム）リッチ版
（2）制作サイトの説明（40文字程度）
自作イラストと音、派手なエフェクトが楽しめるHP制じゃんけんゲームです。
（3）工夫した点・こだわった点
前回実装した基本機能やエフェクトに加え、今回はゲーム性をさらに高めるため「BGMと効果音」を追加しました。グー・チョキ・パーごとに異なる攻撃音を鳴らしたり、クリティカル発生時にド派手な音を鳴らしたりと、アーケードゲームのような臨場感にこだわっています。
（4）難しかった点・次回トライしたいこと（または機能）
プログラムで音を鳴らす際、ブラウザのセキュリティ制限により自動再生がブロックされるという壁にぶつかり、その仕様を調べてON/OFFボタンで解決するまでの過程が難しくも良い学びになりました。
次回は、CSSを使ったレイアウトの微調整を行い、全体の体裁をより美しく整えたいです。
（5）備考（感想、シェアしたいこと等なんでも）
今回、音が鳴るようになったことでゲームとしての完成度が格段に上がり、プログラミングで作る面白さをさらに実感できました！
